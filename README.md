This is my personal website [madbaker.com](https://madbaker.com).  Built in [Eleventy](https://11ty.dev), based on [eleventy-base-blog](https://github.com/11ty/eleventy-base-blog)

When I forget how to do this on a new computer (I just did and I will again):

- install Node.js and NVM https://nodejs.org/en/download

make a dev directory and clone this repo into the directory

```npm install```

will likely get lots of dependency issues if you haven't run this in a while.  Fix them then run

```npm run start```

I'm expecting all kinds of breaking changes but will figure that out as I go.  Lots has happened to 11ty in the year I've been away.
